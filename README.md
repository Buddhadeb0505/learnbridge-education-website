# LearnBridge Education Website
Responsive education and course-provider template built with HTML, CSS, and JavaScript.

## Included
- Responsive homepage and mobile navigation
- Course cards for AI & Automation, Data & Digital Skills, and Career Readiness
- Learning approach section
- Enquiry form demo

## Before publishing
1. Replace LearnBridge with your actual brand name.
2. Update course names, syllabus, fees, duration, delivery mode, instructors, and contact details.
3. Connect the enquiry form to a real email service, CRM, or backend. The current form is demo-only and does not send information.
4. Add your privacy policy and terms.
5. Open `index.html` in a browser to preview.

## Hosting
Upload `index.html`, `styles.css`, and `script.js` to GitHub Pages, Netlify, or another static website host.
